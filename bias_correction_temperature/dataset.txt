1. VISÃO GERAL E OBJETIVO
--------------------------------------------------------------------------------
Este conjunto de dados foi obtido a partir do repositório UCI Machine Learning
Repository ("Bias Correction of Numerical Weather Prediction Model Temperature
Forecast"). O objetivo principal do conjunto de dados é permitir o treinamento
de modelos de aprendizado de máquina para corrigir o viés sistemático das
previsões numéricas de temperatura do modelo regional LDAPS (Local Data Assimilation
and Prediction System) na área metropolitana de Seul, Coreia do Sul.
